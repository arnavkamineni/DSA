# DSA — Data Structures & Algorithms Coursework

Java labs and exercises from a Data Structures & Algorithms course, organized by unit. Each unit pairs a core data structure or algorithm with an applied mini-project rather than a bare textbook exercise.

## Units

| Unit | Topic | Highlights |
|---|---|---|
| 1 | Stacks & Queues | Custom stack/queue implementations |
| 2 | Linked Lists | A Snake game built on a linked-list body, plus a playlist/track linked-list exercise |
| 3 | Hashing | Custom hash map implementation from scratch (`CustomHashMap`) |
| 4 | Sorting | Radix sort with a visual panel, quicksort, and other sorting exercises |
| 5 | Dynamic Programming | Core DP exercises |
| 6 | Tries & Trees | Trie-based autocomplete lab, tree/forest structures |
| 7 | Huffman Coding & Heaps | Huffman compression, plus a priority-queue-based hospital triage simulation |
| 8 | Graphs | Graph traversal, a Hashiwokakero (bridge-puzzle) solver, and MST/shortest-path algorithms themed around the board game Risk |

## Running a unit

Each unit is a self-contained Eclipse Java project under `UnitN.../src/`. Import any unit folder into Eclipse (or add its `src/` to your IDE's source path) and run the unit's `Driver` class.
